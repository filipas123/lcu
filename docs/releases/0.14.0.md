# LCU 0.14.0

**LCU now works with Google Antigravity (experimental), and Pi, Oh My Pi and Codex accept LCU's tools again on newer ChatGPT builds.**

## Changes

- **New experimental adapter: Google Antigravity.** Run `lcu setup --agent antigravity` (alias `agy`) on macOS or Linux. Setup registers LCU's MCP server and lifecycle hooks in Antigravity's shared configuration (`~/.gemini/config/`, or `<project>/.agents/` at project scope), which Antigravity CLI, Antigravity App and Antigravity IDE all read; restart Antigravity afterwards. `--approval auto` adds exact allow rules for `js` and `js_reset` to `~/.gemini/antigravity-cli/settings.json`. Antigravity CLI currently cancels LCU's approval prompt, so the first use of a new app fails and the model is told to run `lcu apps allow <App>`; approving it with Touch ID or your password allows that app for every agent until `lcu apps revoke <App>`. Setup warns about this and asks before going on unless you pass `--yes`. Only Antigravity CLI 1.5.11 on macOS arm64 was tested live; see [Antigravity](https://github.com/amontlabs/lcu/blob/main/docs/ADAPTERS.md#antigravity) for the limits. ([#88](https://github.com/amontlabs/lcu/pull/88), thanks @JamisonDong, who wrote the adapter)
- **Pi and Oh My Pi: LCU's tools no longer break Codex requests.** Newer ChatGPT builds describe the `js` tool with two alternative input forms. Oh My Pi and OpenAI's strict mode could not satisfy that schema, so Codex rejected every request while LCU was enabled. The Pi adapter now registers one flat schema, as the Claude Code adapter already does, and turns strict mode off for LCU's tools. ([#87](https://github.com/amontlabs/lcu/issues/87), [#89](https://github.com/amontlabs/lcu/pull/89), thanks @CandySunPlus for the report)

## Upgrading

Run `lcu update`, then restart the agents that use LCU. To use Antigravity, run `lcu setup --agent antigravity` after updating. To go back, reinstall 0.13.9.
