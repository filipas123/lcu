# LCU 0.13.9

**In T3 Code, computer-use approvals are approval requests again, so only you can answer them.**

## Changes

- **Claude Code in T3 Code: the `lcu-approve` mod leaves app approvals to T3 Code's own approval card.** Since 0.13.7 the mod asked with a question card, and T3 Code treats a question as something an agent may answer. When a subagent asked, the question stayed off the sidebar, and the coordinating agent was told it could answer it, so an agent could approve computer use for an app. T3 Code's approval card is a permission request: it shows as "Pending Approval", on a subagent's parent too, and no agent can answer it. This needs T3 Code 0.1.6 or later; an older T3 Code declines the request, so the app stays unapproved. Released T3 Code offers Approve (allow once), its own "Always allow this session", Decline and Cancel; T3 Code builds that offer the form's own choices add "Always allow". The Claude app and the terminal are unchanged.

## Upgrading

Run `lcu update`; it refreshes the `lcu-approve` mod. Then restart the agents that use LCU. To go back, reinstall 0.13.8.
